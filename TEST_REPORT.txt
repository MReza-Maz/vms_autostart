  Ubuntu 24.04 LTS

Bug fixed (production log 2026-09-27):
  SOAP RetrievePropertiesEx sent invalid PropertyFilterSpec XML
  (intermediate PropertyFilterSpec/PropertySpec/ObjectSpec wrappers
  plus missing required "options" element). Real vCenter returned:
  HTTP 500 - "Required property propSet is missing from data object
  of type PropertyFilterSpec".

  Fix: serialize propSet/objectSet as direct children of specSet and
  include empty <options/>, matching vim25 SOAP encoding rules.
